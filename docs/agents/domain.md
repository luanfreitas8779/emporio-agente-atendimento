# Documentação de domínio

Este repositório tem um único contexto de domínio.

## Leitura inicial

Antes de explorar o código, consulte:

- `docs/01-escopo.md` para requisitos e critérios de aceite.
- `docs/02-arquitetura.md` para componentes e ADRs.
- `docs/03-dados.md` para regras de negócio e qualidade dos dados.
- `docs/04-agente.md` para persona, ferramentas e regras de resposta.
- `docs/05-testes-e-roteiro.md` para os casos de teste.

## Vocabulário

Use os termos da documentação em nomes de testes, tickets e propostas. Se faltar um termo, registre a lacuna em `docs/03-dados.md` ou `docs/04-agente.md`.

## Conflitos com ADRs

Se uma proposta contrariar uma ADR, informe isso explicitamente e indique o motivo para reabrir a decisão.
